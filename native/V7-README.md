# Перекуп V7 — единое оформление

Распакуйте архив в новую отдельную папку и запустите Perekyp.exe. Из прошлой версии перенесите папки saves и Music. Старые модели и seller-ai.exe не нужны.

## Что изменилось
- Остров: больше свободного пространства, единые поля и выравнивание обложки, названия, исполнителя, прогресса и управления.
- Круглые ползунки в плеере и настройках острова. Нажатие сразу выбирает позицию, бегунок следует за мышью, подсказка показывает время или значение. Стрелки клавиатуры работают.
- В плеере время находится по двум краям дорожки, кнопки имеют одну высоту, «Вразброс» переименовано в «Перемешать».
- Общие графитовые поверхности, мятный акцент, обновлённые кнопки, поля, карточки, меню и прокрутка во всех приложениях.
- Акцент из настроек острова применяется ко всей ОС. Светлая тема сохранена; цвет акцента в ней темнее для читаемости.
- При первом запуске V7 включается тёмная тема. После этого выбранная тема сохраняется. Изменить: Настройки → Оформление.

## Музыка
P → Перекуп FM. Для «Моей волны» сначала запустите её в Яндекс Музыке или браузере, затем выберите «Музыка Windows» и нужный плеер. Данные зависят от того, передаёт ли приложение информацию в медиапанель Windows. Внешняя громкость регулируется в приложении.
Поддерживаются локальные папки, прямые аудиоссылки и открытые плейлисты M3U/M3U8, PLS, XSPF, RSS и JSON. Закрытые страницы сервисов открываются в браузере; игра не скачивает их треки.

## Совместимость
Игровая механика и формат сохранений V6 сохранены. Диалоги сценарные, нейросети нет.
Windows EXE собран для x64. В этой среде доступны Linux-проверки интерфейса; запуск Windows EXE и настоящая сессия Яндекс Музыки здесь не проверялись.
