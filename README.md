# Perekup.ru — Windows ZIP

Это отдельная ветка для скачивания готовой локальной версии игры.

1. На странице ветки нажми **Code → Download ZIP**.
2. Распакуй скачанный ZIP целиком в обычную папку.
3. В этой папке запусти **ASSEMBLE.cmd**. Он объединит 15 частей и проверит SHA256.
4. Появится **Perekup-Portable-Windows-x64.zip** — исходный архив размером 481 549 489 байт.
5. Распакуй его целиком и открой **Perekup.exe**.

Не запускай команду сборки прямо внутри окна ZIP. Все файлы `.part01`–`.part15` должны лежать рядом с `ASSEMBLE.cmd`.

Архив разделён только для размещения на GitHub. Содержимое игры не изменено.
Это первая тестовая Windows x64 сборка: C++-оболочка с исходной HTML/CSS/JavaScript-игрой и локальным движком. Полная перепись игровых механик на C++ в неё не входит. Запуск EXE на Windows в среде сборки не проверен.

Иконка встроена. Сохранения и настройки находятся в папке `saves` внутри комплекта. Прогресс из браузера переносится через резервную копию в настройках игры. Подробнее — `README.txt` внутри исходного архива.
