# Perekup.ru

Браузерная игра на HTML, CSS и JavaScript.

Стартовый баланс новой игры и после сброса прогресса — 100 000 ₽. Обычная перезагрузка страницы сохраняет текущий баланс.

Для запуска из корня репозитория:

```sh
python3 -m http.server 8000
```

Прогресс хранится в `localStorage` браузера. Публикация GitHub Pages настроена на ветку `codex/meeting-window` и корень репозитория.

Во вкладке «Сделки» объявления находятся отдельно в разделе «Объявления», сообщения покупателей — во «Входящих», а переписки с продавцами — в «Исходящих». Назначенная встреча остаётся в переписке; сообщение можно открыть, не отправляясь сразу на встречу.

Окно встречи показывает отдельные этапы: ожидание второй стороны (5–15 игровых минут), осмотр машины (5–10 минут) и решение по цене. Оно содержит статусы, прогресс и кнопки действий. После осмотра можно принять скидку/доплату или завершить сделку по согласованной цене. До решения деньги и автомобиль не передаются. Этапы и предложение сохраняются после перезагрузки; закрытие незавершённой встречи означает отъезд и срыв сделки.

Одна реальная секунда равна одной игровой минуте. Когда окно «Часы» активно, одна секунда равна двум минутам. Переключение в другое приложение возвращает обычную скорость.

В часах доступен сон с 22:00 до 09:00: время перематывается до ближайших 09:00. Во время сна продолжают приходить сообщения, а просроченные встречи могут сорваться. Отклики покупателей редкие и случайные: за три игровых часа может не прийти ни одного сообщения или появиться три предложения. У нового игрока один раз появляется предложение открыть справку; её также можно открыть значком на рабочем столе.

Автомобиль можно выставить из гаража по своей цене. Несколько покупателей предлагают меньше, больше или ровно указанную сумму. При наценке больше 500 000 ₽ относительно фактической цены покупки отклики приходят реже. У покупателя есть 15% шанс не приехать на назначенную встречу; в этом случае машина остаётся у продавца, а объявление продолжает работать. Для машин из старых сохранений без цены покупки используется исходная рыночная цена.

Проверки запускаются с Node.js и установленным Playwright:

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/gameplay.cjs
node tests/cities.cjs
```

Тесты используют временный локальный сервер и отдельные браузерные профили. При наличии системного Chromium он используется автоматически; путь также можно задать через `CHROMIUM_PATH`.

В каталог добавлены десять вымышленных коллекционных объявлений (ID 147–156): японские легенды, BMW M3 E30, Ferrari F40, Lamborghini Diablo и Cayenne без фары. Цены, пробеги, описания и продавцы придуманы для игры; фотографии иллюстрируют модели. Атрибуция и лицензии — в [photo-credits.html](photo-credits.html) и [img/legend-sources.json](img/legend-sources.json). Изображение Cayenne изменено с помощью ИИ: удалена одна фара; производное изображение сохраняет лицензию CC BY-SA 4.0.

На рынке доступны выбор города, радиусы 50–2 000 км, поиск по всей России и сортировка по расстоянию. Расстояния считаются по прямой между центрами городов. Выбор города и радиуса сохраняется при перезагрузке. География применяется к рынку; гараж продолжает показывать все купленные машины. Одноимённые города различаются регионом. Справочник содержит 1 117 городов; источник и лицензия приведены в [data/city-source.json](data/city-source.json).

Добавлены каталоги 20 городов сверх Москвы: Санкт-Петербург, Новосибирск, Екатеринбург, Казань, Нижний Новгород, Челябинск, Самара, Омск, Ростов-на-Дону, Уфа, Красноярск, Пермь, Воронеж, Волгоград, Краснодар, Тюмень, Иркутск, Хабаровск, Владивосток и Якутск. В каждом — 30 реальных объявлений в диапазоне 10 000–10 000 000 ₽ и три вымышленные легенды. Источник реальных объявлений — Авто.ру, снимок от 8 октября 2026 года. Цены, характеристики, город и фото проверены на страницах объявлений; имена и характеры продавцов придуманы для игры. В Якутске подходящих объявлений до 100 000 ₽ не было: диапазоны отражают доступные предложения.

Всего в игре 768 машин: прежние 108 сохранены, добавлены 600 реальных и 60 вымышленных. Первые 60 карточек показываются сразу, следующие — кнопкой «Показать ещё». Фото реальных объявлений хранятся в `img/regions/`, а легенды используют фотографии моделей с существующей атрибуцией. Ссылки для проверки — в [data/regional-sources.json](data/regional-sources.json); игровые легенды отмечены отдельно в [data/regional-legends.json](data/regional-legends.json). У машин из прежнего каталога без данных о месте продажи отображается «Город не указан».

Для воспроизводимого импорта используется `python3 scripts/import_city_catalogs.py` со стандартной библиотекой Python. Скрипт сохраняет завершённые городские снимки и их ID, добавляет три игровые легенды на город и прекращает запросы при ответе 429. Кэш незавершённого импорта находится в `/tmp/perekup-city-import`. Список целевых городов — [data/catalog-cities.json](data/catalog-cities.json); скрипт не превращает сохранённые игровые каталоги в живую ленту объявлений. При неполном импорте текущий `regional-cars.js` сохраняется.
