# Разработка Perekup.ru

Игра работает на HTML, CSS и JavaScript без серверной части. Запуск из корня репозитория: `python3 -m http.server 8000`. Прогресс хранится в `localStorage` браузера.

Установите зависимости: `npm install`, затем браузер: `npx playwright install chromium`. Проверки: `npm test`; системный Chromium можно выбрать переменной `CHROMIUM_PATH`.

README — единственный источник текста справки. После редактирования выполните `python3 scripts/sync-help.py`; проверка без записи: `python3 scripts/sync-help.py --check`. Готовая справка встроена в HTML и не требует сетевой загрузки README.

Фоновая музыка находится в `audio/mevison-background.mp3`: игровой MP3 160 кбит/с из предоставленного WAV, автор Mevison. `music.js` управляет запуском после пользовательского действия, повторением, паузой при скрытии страницы и настройкой выключения. Файл не загружается до запуска музыки.

`windows.js` управляет окнами и шестью постоянными кнопками нижней панели. `script.js` содержит игровые действия. `storage.js` записывает только изменённые разделы сохранения. `contracts.js` сохраняет фактическую цену покупки в договоре продажи, чтобы прибыль оставалась доступной после удаления машины из гаража.

Временное предложение сброса при входе выключено флагом `ENTRY_RESET_PROMPT_ENABLED` в `entry-reset.js`. Ручной сброс сохраняет ник, подпись, оформление и настройку музыки.

Метаданные иллюстраций: `data/fictional-photo-sources.json`, `data/custom-photo-sources.json`, `data/trade-photo-sources.json`. Источник географии и лицензия: `data/city-source.json`. Исторические снимки прежнего каталога не используются в игре. Скрипты `scripts/import_city_catalogs.py` и `scripts/redact_photos.py` относятся к старому каталогу: повторный импорт заменит вымышленные игровые объявления.

`settings.js` хранит оформление отдельно в `appearance` и меняет только CSS-тему и обои. `themes.css` задаёт общую палитру и особенности трёх оболочек; приложения используют переменные палитры из `style.css`. Векторные встроенные обои находятся в `wallpapers/`; новые варианты добавляются в `OS_STYLES`. Собственные SVG-иконки общие для всех стилей. Профиль можно редактировать из настроек: при этом заменяется объект профиля, чтобы не менять уже подписанные договоры. Проверки: `npm run test:settings`.

`desktop-visuals.js` и `desktop-visuals.css` реализуют композицию утверждённых макетов: компактный каталог, строку статистики, отдельное окно переписки, панели с подписями и разворачивание окон. Объекты переписки, цены и этапы сделки остаются в прежних игровых обработчиках. Фоны `ribbons.jpg`, `valley.jpg`, `facets.jpg` созданы из визуальных макетов инструментом imagegen; остальные варианты сохраняют лёгкие SVG-фоны. Сетка ярлыков мигрирует один раз, затем снова сохраняет пользовательские позиции. Проверки интерфейса: `npm run test:visuals`.

`expanded-cars.js` загружается после исходных каталогов и перед `city-market.js`. Дополняет авторынок до 4 200 объявлений: фиксированный список моделей, зарезервированные ID и расчёты без случайности сохраняют идентичность машин между входами. Иллюстрации берутся только у исходной модели; состояние, комплектация и стоимость заявленного восстановления хранятся у экземпляра. `carStory()` использует эти сведения для диагностики и подготовки. Проверки каталога: `node tests/expanded-market.cjs`.

Городские фото: `city-photos.js` использует `city-vehicle-masks.js`, исходные фото и атлас `img/cities/russian-city-backdrops-v1.webp`. Фон выбирается по городу объявления либо фактическому городу своей машины. Маски и разметка панелей общие для повторных экземпляров; постоянные ID задают кадрирование и цвет поддерживаемых моделей без случайного изменения при перезагрузке. Проверки: `node tests/city-photos.cjs`.
